## 二、使用

- **切皮肤**: 播放器右键菜单选皮肤(DeepSeek Whale); 或主配置 `<Skin PackageName="DeepSeekWhale.skn"/>`。
- **宠物**: 双击启动器。左键按住拖动(只拖得到本体, 透明区自动穿透); **双击=喂饭**; 右键菜单=喂饭/睡觉/玩耍/窗口置顶/退出; 位置记忆在 `AddIn\whale.ini`; 会随机待机→走动→吃饭→睡觉。
- **改美术**: 改 `gen_skin.py`(皮肤)/`gen_pet.py`(宠物) → `python gen_skin.py` → 拷 `DeepSeekWhale.skn` 进 `Skin\`; 宠物重建见下。

## 三、关键技术事实(实证)

1. **.skn = ZIP**: PK 头, deflate, 位图+Skin.xml+Visual.xml+Playlist.xml+Lyric.xml+TTPlayer.ico 在包根。`tools\pack_skn.py` 打包; TT-07 重打包回灌原版渲染一致(闭环验证)。
2. **Skin.xml 必须无 `<?xml?>` 声明行且纯 ASCII**, 否则原版解析器整体拒绝→回落默认皮肤(实测踩坑)。皮肤名/字体因此用英文(DeepSeek Whale / Microsoft YaHei UI)。
3. **按钮帧约定(照 TT-07)**: 位图=4 帧横排条带(普通/悬停/按压/备用), 帧=位图宽/4; number.bmp=12 格(0-9 `:` `-`)各 10×14; 滚动条 3 帧条带; EQ 填充条 eqfactor_full(4×60 竖)/full2(60×4 横); 控件 rect 与帧同尺寸最稳。
4. **频谱/列表/歌词配色权威 = 主配置 TTPlayer.xml 的 Visual/PlayList/Lyric 节点**; 皮肤包内 Visual.xml 不被读取; `<皮肤名>.skn.xml` 边车只在 UI 切换皮肤时套用(已预置)。图标控件画的是 exe 类图标(橙色千千球), 皮肤内 TTPlayer.ico 启动时不生效(LoadImageA 实测我的 ico 有效, 引擎不用)。
5. **火绒(HipsDaemon)实时删除编译器新链接的 exe**(copy 也拦, ren/move 同文件改名不拦): 宠物编译配方 = `gcc -o NTTWhale.dat ...` → `ren NTTWhale.dat NTTWhale.exe` → `move` 到 AddIn。全新 exe 若直接 -o .exe 秒被吃。
6. MinGW 单文件编译在中文路径下 ld 会哑火: 一律在 `D:\TTPlayer\.workbuddy\whaletmp`(纯 ASCII)里编译。
7. 本机 ACP=936; 宠物菜单用 UTF-8 字面量+Wide API 输出中文, 不经 ANSI。
8. **宠物位图生成铁律**(v6 踩坑闭环): LANCZOS 缩放会把半透明像素与品红背景混色→"看着透明"。顺序必须是 `decontaminate`(先贴到描边色底再带 alpha)→ 缩放/变换 → 二值 alpha(>=128)硬贴 → 3x3 闭运算 → `plug_holes` 洪泛补洞; 配件(水珠/泡泡/星光)一律实心填充避免环形包洞。`tools\check_pet.py` 数值体检(洞=0/渗色=0), `tools\cap.py` 抓 PrintWindow 帧与源图逐像素比对(键色区在抓图中呈黑色属 DWM 正常现象)。

## 五、重建命令备忘

```bat
:: 皮肤
python D:\TTPlayer\.workbuddy\胖鲸鱼皮肤\gen_skin.py
copy /y D:\TTPlayer\.workbuddy\胖鲸鱼皮肤\DeepSeekWhale.skn D:\TTPlayer\Skin\

:: 宠物(必须 .dat+ren 绕火绒; 全程 ASCII 路径)
python D:\TTPlayer\.workbuddy\胖鲸鱼皮肤\gen_pet.py D:\TTPlayer\.workbuddy\whaletmp\frames
copy /y D:\TTPlayer\.workbuddy\胖鲸鱼皮肤\whale.c D:\TTPlayer\.workbuddy\whaletmp\
cd /d D:\TTPlayer\.workbuddy\whaletmp
D:\mingw32\bin\windres.exe --input-format=rc -O coff -i whale.rc -o whale_res.o
D:\mingw32\bin\gcc.exe -m32 -O1 -mwindows -finput-charset=UTF-8 -o NTTWhale.dat whale.c whale_res.o -lgdi32 -luser32 -lshell32
ren NTTWhale.dat NTTWhale.exe
move /y NTTWhale.exe D:\TTPlayer\AddIn\NTTWhale.exe
```
(whale.rc 内容: `1..5 RCDATA "frames/idle|walk|eat|sleep|happy.bmp"`)

> **必须带 `-finput-charset=UTF-8`**: 源码里的菜单文案是 `L"中文"` 宽字面量, gcc 靠这个开关按 UTF-8 读源码再转 UTF-16。漏掉它会按本地 ACP(936) 解析, 中文全部变乱码。
>
> **不要手写 `\xNN` UTF-8 字节**: 2026-10-29 修过一次 —— 菜单里三条文案(`跟随`/`问候`/`害羞`)的字节被拼错一位, 编译零警告, 但运行时显示成「路随电者自动」「恭望」「宜定」, 因为错出来的仍是合法汉字, 肉眼扫菜单根本发现不了。**一律用 `L"中文"`。**
