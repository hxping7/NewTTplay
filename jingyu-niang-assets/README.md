# 鲸鱼娘 Q 版角色素材包

「DeepSeek 鲸鱼娘」Q 版化 IP —— 深蓝女仆装 + 白饭碗 + 鲸鱼尾巴。

- `frames/` 共 90 张透明底 PNG：17 张状态图 + 73 张相位帧
- 19 组相位循环（L00–L18），每组附条带预览 PNG 与循环 GIF
- `表情差分/` 8 个 256×256 表情头像 + 差分总览表
- `三视图/` 正面 / 正侧面 / 正背面设定稿
- 桌面宠物 `AddIn/NTTWhale.exe` 的帧素材取自本包（见「五」）

## 五、接入桌宠引擎

桌宠源码在 `AddIn/NTTWhale-src/`（`whale.c` + `whale.rc`），
帧由 `tools/imgtool/gen_pet_bmp.js` 从本素材包转换：

| 项 | 引擎规格 | 素材包 | 转换方式 |
|---|---|---|---|
| 单帧尺寸 | 128×128 | 1024×940（L18 1200×940） | 等比缩放至 128×128 内，底部基线对齐 |
| 条带格式 | 横排 BMP，宽 = 帧数×128 | 独立 PNG | 横向拼接为条带 |
| 位深 | 24bpp BMP | 32bpp PNG | 转 24bpp |
| 资源 | RCDATA 1..18 | `S<序号>_<状态>` | 状态名一一映射 |

RCDATA 编号（见 `AddIn/NTTWhale-src/whale.rc`）：

```
1 idle   2 walk   3 feed   4 eat    5 sleep  6 happy  7 sad
8 work   9 music  10 ktv   11 angry 12 swim  13 greet 14 drag
15 shy   16 think 17 proud 18 dance
```

引擎状态号 `g_state` = RCDATA − 1（0 起计）。交互映射（`whale.c`）：
单击摸头 → `shy`；双击 → `feed`；按住拖动 → `drag`（松手回待机）；
右键菜单直选各状态；平时由随机行为表按权重轮换全部 18 个状态。
转换脚本依赖见 `tools/imgtool/package.json`（`sharp`；循环 GIF 另用 `gifencoder`）。

用途：皮肤状态提示、桌宠交互反馈、聊天头像、表情包底图。

### 从总览表切出单个头像

```bash
NODE_PATH=./.workbuddy/imgtool/node_modules \
  node tools/imgtool/expr_sheet_split.js <总览表.png> <输出目录> 256
```

脚本做四件事：**边缘泛洪抠背景**（保留角色内部的白围裙/白皮肤）→ **按行带 + 等分点附近最低密度列切 8 格**
→ **反合成去灰边**（边界像素按与背景的色差算软 alpha，再解出原色）→ **抹掉右下角 AI 水印**。
