命名 `L<序号>_<状态>_<序号>.png`，1024×940 透明底。所有组底部基线已对齐（偏移 = 0）。

| 组 | 帧率 | 四帧相位 | 循环 GIF |

### L18_dance 摇尾巴跳舞（8 帧 · v3 新增）

命名 `L18_dance_<序号>.png`，1200×940 透明底。帧率 150ms，循环 GIF：`鲸鱼娘循环_L18_dance_摇尾巴跳舞.gif`。

| 帧 | 手臂位 | 尾巴位 | 身体 | 备注 |
|---|---|---|---|---|
| 0 | 垂手 | 低位（拖地） | 中立 | 起始相位 |
| 1 | 垂手 | 低位 | 左倾 5° | |
| 2 | 肩侧屈肘 | 中位 | 中立 | 弹跳 +16px |
| 3 | 肩侧屈肘 | 高位（甩起） | 中立 | 弹跳 +16px |
| 4 | 肩侧屈肘 | 上翘 | 右倾 5° | |
| 5 | 高举过头顶 | 高位 | 中立 | |
| 6 | 高举过头顶 | 中位 | 左倾 5° | |
| 7 | 垂手 | 后方 | 中立 | 接回第 0 帧 |

设计要点：
- **动效主体是尾巴**——Q 版长裙摆遮住腿，128px 下身体微动不可读，只有尾巴的大幅上下扫动与手臂高低差能被辨识
- 身体左右倾采用**支点旋转**（绕脚底），保证双脚踩地不漂移
- 水平对齐用**裙摆中央条带**做锚点（不是整体包围盒），否则尾巴甩向哪边角色就往哪边偏

## 五、接入 whale.c 引擎的规格说明

现有引擎（`.workbuddy/胖鲸鱼皮肤/whale.c`）规格：

| 项 | 现有引擎 | 本素材包 | 转换方式 |
|---|---|---|---|
| 单帧尺寸 | 96×96 | 1024×940 | 等比缩放至 96×96 内，底部基线对齐 y=96 |
| 条带格式 | 768×96 横排（8帧） | 独立 PNG | 横向拼接为 `帧数×96` 宽的条带 |
| 位深 | 24bpp BMP | 32bpp PNG | 转 24bpp BMP |
| 资源编号 | RCDATA 1..11 | — | 状态名一一映射 `S<序号>_<状态>` → RCDATA 序号 |

### 建议的 RCDATA 编号（对齐现有 11 个 + 新增）

```
1  idle     ← S00_idle       2  walk    ← S01_walk
3  eat      ← S02_feed       4  sleep   ← S04_sleep
5  happy    ← S05_happy      6  sad     ← S06_sad
7  work     ← S07_work       8  music   ← S08_music
9  ktv      ← S09_ktv        10 angry   ← S10_angry
11 swim     ← S11_swim       12 greet   ← S12_greet
13 drag     ← S13_drag       14 shy     ← S14_shy
15 think    ← S15_think      16 proud   ← S16_proud
17 eat_self ← S03_eat
```

### 状态机接线建议（对应 whale.c 现有逻辑）

- **单击（摸一摸）** → 建议从 `happy` 改为 `shy`（捂脸红晕），欢呼举碗幅度过大不适合摸头反馈
- **双击（喂饭）** → 应走 `feed`（张嘴等投喂），而非 `eat`（她自己吃饭，语义相反）
- **拖拽中** → 挂 `drag` 状态（引擎已有 `g_dragMoved` 标志可直接挂）
- **随机游走** → `walk` 已有侧身帧，引擎的水平镜像逻辑可直接复用
- **待机呼吸** → `idle` 换成 `L00_idle` 四帧循环，最长驻状态加上起伏会明显"活"

## 六、制作说明

- 全部画面 1024×1024 生成，裁去右下角平台水印后输出 1024×940
- 抠图用「边缘泛洪连通域」：从画面边缘采样聚合平坦背景色，再从边缘泛洪，只删除连通且颜色平坦的区域。角色内部的白围裙、白皮肤、深色描边均完整保留（纯色键控会误删这些区域）
- 相位帧生成技巧：**用该状态的现有帧作参考图**（而非主形象），提示词里只写"改变哪个部位"并强调其他一切不变，这样循环时不会跳变
- 摇尾巴与游泳两组首版不合格（尾巴被重绘成不同形态而非角度旋转、水线高度不一致导致循环时水面跳动），已用"锁形状只改角度"、"锁水线高度"重做
- 重新合成脚本：`.workbuddy/imgtool/build2.js`（抠图 + 对齐 + 帧表 + GIF）
- 图像依赖：`sharp` + `gifencoder`（Node 侧，本机 pip 装不了 Pillow）
