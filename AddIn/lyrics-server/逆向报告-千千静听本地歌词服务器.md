# 千千静听本地歌词服务器 — 逆向分析与 Win11 替代实现

> 一期交付：逆向 NCAB 插件 → 复刻协议 → Node.js 替代服务器（Win11 Smart App Control 兼容）
> 分析工具：REA 6.7.0（Reverse Engineer Anything）+ Ghidra 12.1.4 + UPX 5.2.1
> 日期：2026-10-18

---

## 1. Win11 无法运行的根因（已实证）

| 项目 | 结论 |
|---|---|
| 故障现象 | NCAB.exe 无法启动；PowerShell Start-Process 报错 |
| 错误信息 | 「应用程序控制策略已阻止此文件。**恶意二进制信誉**。」 |
| 根因 | **Smart App Control 强制模式**（`HKLM\SYSTEM\CurrentControlSet\Control\CI\Policy\VerifiedAndReputablePolicyState = 1` = Enforce） |
| 被拦对象 | NCAB.exe（UPX 加壳、无签名、云端信誉差）、update.exe（ASPack 加壳）——加壳+无签名+低流行度 = 典型拦截特征 |
| 附带风险 | plugin\3.KuGou.dll 同为 UPX 加壳，即使 NCAB 能启动也可能在 LoadLibrary 阶段被拦 |
| 修复限制 | SAC 一旦 Enforce 只能重装系统才能关闭；给 NCAB 签名不现实（无代码签名证书） |
| 结论 | **原版插件在本机无法修复，必须替换实现** |

> 佐证：bash 直接执行同样返回 Permission denied；TTPlayer.exe（未加壳、有历史运行记录）可正常启动——拦截是针对二进制信誉的，不是针对所有旧软件。

## 2. 插件架构（逆向结论）

```
TTPlayer.exe (x86)
   └─ AddIn\ttp_lrcsh.dll           [TTPlayer 歌词插件，导出 ttpGetSoundAddIn]
        ├─ 读取 AddIn\ttp_lrcsh.ini  → query_url = http://127.0.0.1:89/
        ├─ ttpcomm.dll               → 获取当前播放歌曲的歌手/歌名
        └─ HTTP GET（WinINet，UA: Mozilla/4.0 MSIE 6.0）
             ↓
NCAB.exe (x86 易语言, UPX 加壳)      [本地歌词服务器，端口 89]
   ├─ 正则解析参数（Artist=(.*?)& 等）
   ├─ 枚举 plugin\*.dll → LoadLibrary → GetProcAddress("enter"/"down")
   ├─ 聚合各插件返回的 <lrc .../> 片段，包装 <result> XML
   ├─ 自带 HTML 页面（http://localhost:89 显示 歌手/歌名/下载歌词）
   └─ 在线更新（muaini.cn/tools/ttplay/*.txt）
             ↓
   plugin\1.QQ.dll     → QQ音乐   smartbox_new.fcg 搜索 + fcg_query_lyric_new.fcg 歌词
   plugin\2.Netease.dll→ 实为酷我（文件名遗留，无网易云实现）
   plugin\3.KuGou.dll  → 酷狗     mobilecdn 搜索 + krcs/lyrics.kugou.com 下载（UPX 加壳）
   plugin\4.KuWo.dll   → 酷我     searchMusicBykeyWord + songinfoandlrc
```

## 3. 协议规范（ttp_lrcsh.dll Ghidra 反编译实证）

证据：REA search/xrefs/decompile，ttp_lrcsh.dll（image base 0x60350000，sha256 4c31c653…）

### 3.1 搜索请求（FUN_6035249b）

```
GET {query_url}?sh?Artist={A}&Title={T}&Flags={F}&ci=
```
- A/T：**UTF-16LE 字节的大写十六进制**（经典千千协议；歌词正常化：去空格/单引号、小写由服务端处理）
- F：Flags，通常 0
- ci=：附加参数，NCAB 忽略

### 3.2 搜索响应（XML，UTF-8）

```xml
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<result>
  <lrc id="12345" artist="周杰伦" title="晴天" type="QQ"/>
  ...
</result>
```
- 根元素 `<result>`；子元素标签名 **`lrc`**（.data:0x60359170）
- lrc 属性：**`id`**（必须为十进制整数，atoi 解析）、`artist`、`title`（.data:0x6035916c/0x60359164/0x60359118）
- 无结果时根元素携带 `errcode`/`errmsg`（errcode 缺失 → 32010）
- ttp_lrcsh.dll 内置消息：Can not find the lyrics / Lyrics server is not started / Lyrics server is maintaining …

### 3.3 下载请求（FUN_60352b30）

```
GET {query_url}?dl?Id={id}&Code={code}&ci=
```
- id：搜索响应中的 `<lrc id>`（%d 格式化）
- code：附加校验，替代服务端可忽略

### 3.4 下载响应

- **原始 LRC 文本**（`[ti:][ar:][al:][offset:]` + 时间戳行），Content-Type 任意
- **不得以 `<result ` 开头**——插件以首 8 字节区分：`<result ` → 错误 XML（解析 errcode/errmsg）；否则 → 原始歌词（自动反转义 `&amp; &lt; &gt; &quot; &apos; &#x..`）

### 3.5 错误响应

```xml
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<result errcode="32010" errmsg="Can not find the lyrics"/>
```

## 4. NCAB 服务端行为（解包 + 字符串实证）

- UPX 解包后 2,183,168 字节；易语言编写（EPL 内核错误文本、code_page(936)）
- 请求解析：正则 `Artist=(.*?)&` / `Title=(.*?)&` / `Id=(.*?)&`
- 插件契约：`plugin\*.dll` 导出 **`enter`（搜索）/ `down`（下载）**，返回 `<lrc id="%s" sid="%s" artist="%s" title="%s" type="%s"/>` 片段
- 响应头：`Content-type: text/html; charset=UTF-8`；`Set-Cookie: geiquname=%s`（HTML 界面用）
- 配置 XML：`<ttp_lrcsvr query_url="http://127.0.0.1:%s/"><server name="NCAB本地接口" url="..."/><extra title="..." url="https://www.muaini.cn/?p=754"/></ttp_lrcsvr>`
- 上游 UA：`Mozilla/5.0 (Windows NT 6.1; WOW64; rv:46.0) Gecko/20100101 Firefox/46.0`
- 启动文案：「框架启动成功,已加载了…」「未发现可用的歌词插件。当前歌词服务不可用」

## 5. 替代实现（本期交付物）

`server.js` — Node.js 单文件、零依赖，完整复刻 3.x 协议：

| 能力 | 状态 |
|---|---|
| `?sh` 搜索（hex/明文双兼容解码） | ✅ |
| `?dl` 下载（整数 id 注册表 + JSON 持久化） | ✅ |
| XML 响应/实体转义/错误码 | ✅ |
| QQ音乐（smartbox 搜索 + 歌词 base64） | ✅ 实测 4~14 条 |
| 酷狗（mobilecdn 搜索 + krcs/lyrics 下载） | ✅ 实测 10 条 |
| 酷我（searchMusicBykeyWord + songinfoandlrc） | ⚠️ API 已加 csrf 反爬（2022 年后变更），代码保留、返回空，待适配 |
| HTML 状态页（http://localhost:89） | ✅ |
| 请求日志（log/yyyy-MM-dd.txt，兼容原版格式） | ✅ |

**启动**：双击 `启动歌词服务器.cmd`（或 `node server.js`）。端口 89 与 ttp_lrcsh.ini 一致，TTPlayer 侧零配置。

**验证**：`node test-client.js`（复刻 ttp_lrcsh.dll 客户端行为）——搜索 14 条 / 下载原始 LRC 通过。
